# TelePort

Telegram-бот для продажи и управления VPN-подписками.

## Возможности

- Регистрация пользователей через Telegram
- Выбор тарифа (1 / 3 / 6 / 12 месяцев)
- Выбор локаций (Нидерланды, Германия, Финляндия, США, Латвия)
- Создание платежа
- Ручное подтверждение оплаты администратором
- Интеграция с Marzban (создание пользователя и выдача ссылки)
- Просмотр активной подписки

## Стек

- **Go** 1.25
- **PostgreSQL** 16
- **Telegram Bot API** (`gopkg.in/telebot.v4`)
- **Marzban**
- **Docker** + Docker Compose
